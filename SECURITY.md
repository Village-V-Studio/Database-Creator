# Security Policy

## Supported Versions

Currently, the following versions of DBC (Database-Creator) are supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅                 |
| < 1.0   | ❌                 |

## Reporting a Vulnerability

Security is a top priority for this project. To ensure the safety of all DBC users, please follow these guidelines when reporting issues:

### 🐛 Normal Bugs (Public Issues)
If you find a standard bug (e.g., "a command doesn't work", "the program crashes", "a typo in the logs"), please **open a public Issue** in this repository.

### 🛡️ Security Vulnerabilities (Private Report)
If you discover a vulnerability that could be exploited by an attacker (e.g., "a way to bypass authentication", "access to unauthorized databases", "arbitrary file read/write"), please do **NOT** create a public GitHub issue. 

Instead, please report it privately so we have time to fix it before it becomes public knowledge and puts other servers at risk.

### How to report:
1. Go to the **Security** tab of this repository on GitHub.
2. Select **Advisories** from the left sidebar.
3. Click on the **Report a vulnerability** button.
4. Provide a detailed description of the issue, including steps to reproduce it and any potential impact.

We will review all reports and make every effort to acknowledge and resolve vulnerabilities as quickly as possible.
